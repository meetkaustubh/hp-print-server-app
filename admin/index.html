Test lab

Try the whole customer journey without real money, and force things to go wrong to check refunds and alerts. Test payments never count as revenue and never reach Razorpay.

The payment outcome is chosen by you on the test payment window: Pay successfully or Decline the payment.

Open the customer page

  1. Switch test mode on, then open the customer page (a yellow bar shows it is in test mode).
  2. Upload a file and press Pay. Choose success or decline in the test window.
  3. Set the print outcome to “printer failed” to see the automatic refund. Set the refund to “fails” as well to see the failed-refund alert and the Retry refund button in Jobs.

Payments

Set up the webhook in Razorpay so payments are never lost if a customer closes their browser: Dashboard → Settings → Webhooks → add with events payment.captured and order.paid, and paste the secret you choose above. Live payments need your site on HTTPS (see the README, Cloudflare Tunnel).
